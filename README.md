# 10 Problems Solved in Python

This repository contains solutions to 10 different problems implemented in Python. Each problem demonstrates a specific programming concept and provides a practical example of how to solve it.

## Problems Covered

1. **Interest Calculator**: A program that calculates simple interest based on user input for principal amount, rate of interest, and time.
2. **Even Odd Check**: A program that checks whether a given number is even or odd.
3. **Grade Calculator**: A program that assigns a grade based on user input marks.
4. **Multiplication Table**: A program that generates a multiplication table for a given number.
5. **Sum of Digits**: A program that calculates the sum of the digits of a given number.
6. **Reverse a Number**: A program that reverses the digits of a given number.
7. **Prime Number Check**: A program that checks if a given number is prime.
8. **Sum of Natural Numbers**: A program that calculates the sum of natural numbers up to a given number using both for and while loops.
9. **Simple Calculator**: A program that performs basic arithmetic operations based on user input.
10. **Number Pattern Printing**: A program that prints a pattern of asterisks based on user input.

## Usage

To run any of the programs, simply execute the `10problems.py` file in a Python environment. Make sure to provide the necessary inputs as prompted by the program.
